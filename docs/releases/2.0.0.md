# EdgeAurora 2.0.0

The first release of EdgeAurora, a fork of
[EdgeBeat](https://github.com/ChaitanyaSai-Meka/EdgeBeat) 1.4.0 by Chaitanya Sai
Meka, rebuilt around a GPU renderer and an aurora look.

## Highlights

- The glow is drawn by one Metal shader in four edge strips instead of a
  full-screen SwiftUI canvas. With Apple Music playing on an M3 Pro MacBook Pro,
  CPU went from about 41% to 7–12% and memory from about 327 MB to 150–190 MB.
  With nothing playing, it sits at about 1% CPU.
- An aurora ribbon runs along every edge, with the spectrum laid around the
  screen: bass along the bottom, mids up the sides, treble across the top.
- Rays live on their own clocks. Kicks spark them along the bottom; snares and
  hi-hats spark them across the top.
- Colours come from the album art. They are blended in OKLCH, output in Display
  P3 and crossfaded between tracks, and near-greyscale covers still get colour.
- Menu › Aurora has Frosted Glass, Halo, Reactivity, Ray Length and Smoke. Each
  slider's midpoint is the default look.
- Check for Updates now follows EdgeAurora's releases instead of EdgeBeat's.

## Fixes

- Track detection no longer hangs when Spotify isn't installed.
- The hidden Now Playing window no longer keeps rendering.

Both fixes are also offered upstream in
[EdgeBeat#3](https://github.com/ChaitanyaSai-Meka/EdgeBeat/pull/3).

## Installing

Download `EdgeBeat.zip` below, unzip it and move `EdgeBeat.app` to
`/Applications`. It is built for Apple silicon and needs macOS 14.4 or later.

The build is not notarized, so macOS blocks the first launch and says it cannot
verify the app. Click Done, open System Settings › Privacy & Security, scroll to
the message about EdgeBeat and click Open Anyway. Then allow system audio
recording and, if asked, control of Music or Spotify.

The app inside is still named EdgeBeat with the same bundle identifier, so it
replaces an installed EdgeBeat and keeps its settings. macOS asks for the audio
and automation permissions again, because this build is signed differently.
